# AI Usage Disclosure

Generative AI tools were used to support the development and documentation of this MAI 600 final capstone project.

ChatGPT was used for:
- Brainstorming and refining the project structure
- Assisting with Python code development and debugging
- Organizing evaluation procedures and test cases
- Improving explanations, documentation, and README content
- Supporting the preparation of the final academic article

Ollama with Llama 3.2 3B was used as the local language model baseline for evaluation.

All project decisions, implementation steps, test execution, evaluation results, screenshots, interpretations, and final submissions were reviewed and verified by the student.

The orthodontic knowledge base used in this project contains fictional administrative information only. No real patient information or protected health information was used.
